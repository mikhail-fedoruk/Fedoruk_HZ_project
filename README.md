# Моделирование температурных зон

Автор: Федорук Михаил Сергеевич.
Научный руководитель: Дедов Евгений Олегович.

## Назначение
Учебная модель равновесной температуры в одиночных
и двойных звёздных системах. Программа строит
температурные карты и выделяет диапазон 0–100 °C.
В двойном режиме доступен выбор орбитальной фазы.
Этот критерий не доказывает обитаемость планеты.

## Установка и запуск
Требуется Python, NumPy и Matplotlib.
Скачайте код через Code → Download ZIP и распакуйте.
Откройте терминал в папке с main.py и выполните:

    python -m pip install -r requirements.txt
    python main.py

## Файлы
main.py — интерфейс и запуск.
physics.py — физические расчёты.
models.py — описание объектов и параметров.
constants.py — константы и единицы измерения.
utils.py — вспомогательные проверки.

## Ограничения
Не моделируются атмосфера и динамическая устойчивость
планетных орбит. Двойной режим использует большой
объём памяти: два основных массива занимают около
2,39 ГиБ, не считая остальных данных.
